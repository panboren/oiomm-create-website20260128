# 🎨 酷炫模板动画使用指南

## 📋 概述

本项目新增了8个极具创意的滚动模板动画，基于GSAP和ScrollTrigger打造电影级的视觉体验。

## 🚀 新增模板列表

### 1. threeDCardFlipAnimation - 3D卡片翻转
**效果描述**: 面板随着滚动进行3D翻转效果，左右交替翻转方向

**特性**:
- 3D rotationY翻转动画
- 缩放和透明度过渡
- 交替方向（左/右）
- 平滑的power2.out缓动

**适用场景**:
- 产品展示
- 简介页面
- 特性介绍

**参数限制**:
- ✅ 横屏支持
- ✅ 竖屏支持

---

## 📦 使用方法

### 在编辑器中使用

1. 打开模板编辑页面
2. 在模板下拉菜单中选择新模板
3. 根据模板的限制选择横屏或竖屏
4. 保存并预览效果

### 在代码中调用

```javascript
import { UseAnimation } from '~~/pages/edit/hooks'

const animation = UseAnimation()

// 调用模板（返回cleanup函数）
const cleanup = animation.threeDCardFlipAnimation()

// 清理动画
cleanup()
```

## 🌟 最佳实践

1. **选择合适的模板**
   - 根据主题风格选择
   - 考虑内容类型
   - 测试性能表现

2. **优化面板数量**
   - 粒子效果建议3-5个面板
   - 复杂动画建议不超过6个面板

3. **配色搭配**
   - 粒子动画适合深色背景
   - 分形效果适合渐变背景
   - 玻璃破碎适合明亮背景

4. **内容设计**
   - 留出足够的空间展示动画
   - 避免过多的文字内容
   - 使用高质量图片
