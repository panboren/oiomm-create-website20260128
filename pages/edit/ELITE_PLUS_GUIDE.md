## 🎨 模板详解

### V36: 平滑横向 (smoothHorizontalAnimation)

#### 核心特性
```javascript
scrub: 1.5  // 更平滑的滚动关联
ease: 'power2.inOut'  // 更自然的缓动
anticipatePin: 1  // 提前预判

// 动画效果
x: -100 → 0
opacity: 0 → 1

// 额外的微妙效果
y: 0 → -20 → 0  // 垂直浮动
```

#### 优化点
1. **更平滑的scrub**: 1.5而不是1，滚动更柔和
2. **power2.inOut**: 双向加速减速，更自然
3. **垂直浮动**: 添加了y轴的微动，更有生命力
4. **anticipatePin**: 提前预判滚动，减少卡顿

#### 适用场景
- 产品展示
- 图片轮播
- 内容切换
- 简洁风格的网站

---

### V37: 弹性缩放 (elasticScaleAnimation)

#### 核心特性
```javascript
ease: 'back.out(1.7)'  // 强烈的弹性过冲
scrub: 1.8  // 中等滚动关联

// 动画效果
scale: 0.3 → 1.2 → 1  // 先放大再回到正常
opacity: 0 → 1

// 额外的旋转
rotation: 0 → 5 → 0  // 轻微旋转
```

#### 优化点
1. **back.out(1.7)**: 过冲系数1.7，弹性感强烈
2. **先放大再缩小**: 模拟弹簧效果
3. **轻微旋转**: 增加动感但不夸张
4. **中等scrub**: 1.8，保证弹性效果可观察

#### 适用场景
- 按钮点击
- 卡片进入
- 弹窗动画
- 有活力的产品

---

### V38: 无限循环优化 (infiniteSmoothAnimation)

#### 核心特性
```javascript
// 节点克隆
const clone = panels[0].cloneNode(true)
panels[0].parentNode.appendChild(clone)

// Pin所有面板
pin: true
pinSpacing: false

// Snap吸附
snapTo: 1 / (panels.length)
inertia: false

// 动画效果
opacity: 0 → 1 → 0
scale: 0.95 → 1 → 0.95
rotation: 0 → 2 → 0
```

#### 优化点
1. **无缝衔接**: 克隆首尾，循环无感知
2. **snap吸附**: 自动对齐到面板
3. **轻微旋转**: 添加2°旋转，更有动感
4. **scrub 1.2**: 平滑但不拖沓

#### 适用场景
- 轮播图
- 无限滚动列表
- 内容展示
- 长页面浏览

### V39: 淡入上移 (fadeUpAnimation)

#### 核心特性
```javascript
ease: 'power3.out'  // 平滑的减速
scrub: 1.5  // 适中滚动关联

// 动画效果
y: 80 → 0
opacity: 0 → 1

// 额外的倾斜
skewX: 0 → 1 → 0  // 轻微倾斜
```

#### 优化点
1. **power3.out**: 强烈的减速，落地感强
2. **经典组合**: y + opacity是最经典的效果
3. **轻微倾斜**: skewX 1°，增加细节
4. **从下往上**: 符合阅读习惯

#### 适用场景
- 内容卡片
- 文章列表
- 产品介绍
- 任何需要淡入的场景

### V40: 交错横向 (staggeredHorizontalAnimation)

#### 核心特性
```javascript
stagger: 0.15  // 交错延迟
scrub: 1.5  // 适中滚动关联

// 动画效果
x: (i % 2 === 0 ? -100 : 100) → 0  // 奇偶相反方向
opacity: 0 → 1

// 持续摆动
rotation: 0 → 1 → -1 → 0  // 轻微摆动
duration: 2 + Math.random()  // 随机时长
```

#### 优化点
1. **stagger延迟**: 0.15秒，层次感明显
2. **奇偶相反**: 奇数从左，偶数从右
3. **持续摆动**: infinite repeat，永不停止
4. **随机时长**: 2-3秒，避免同步

#### 适用场景
- 多元素列表
- 卡片网格
- 图片展示
- 需要层次感的场景

---

### V41: 缩放淡入 (scaleFadeAnimation)

#### 核心特性
```javascript
ease: 'power2.out'  // 平滑减速
scrub: 1.2  // 紧凑滚动关联

// 动画效果
scale: 0.7 → 1
opacity: 0 → 1
filter: 'blur(10px)' → 'blur(0px)'  // 模糊到清晰

// 额外的阴影
boxShadow: 'none' → '0 20px 40px rgba(0,0,0,0.3)' → 'none'
```

#### 优化点
1. **中心缩放**: 从0.7到1，不会太小
2. **模糊到清晰**: filter效果增强立体感
3. **阴影变化**: 添加和消失阴影
4. **紧凑scrub**: 1.2，响应快

#### 适用场景
- 模态框
- 弹出层
- 卡片展示
- 需要强调的内容

---

### V42: 无限旋转 (infiniteRotateAnimation)

#### 核心特性
```javascript
// 无限滚动（同V38）
clone + pin + snap

// 动画效果
opacity: 0 → 1 → 0
scale: 0.9 → 1 → 0.9

// 持续旋转（每个面板不同速度）
rotation: 0 → 360
duration: 20 + index * 5  // 20-60秒
repeat: -1
ease: 'none'
```

#### 优化点
1. **无限旋转**: 每个面板持续旋转
2. **不同速度**: 20-60秒，避免单调
3. **360度完整**: 整圈旋转，无跳变
4. **ease: none**: 线性旋转，速度均匀

#### 适用场景
- 品牌展示
- Logo轮播
- 创意设计
- 需要持续动效的场景

---

### V43: 平滑组合 (smoothComboAnimation)

#### 核心特性
```javascript
ease: 'power3.inOut'  // 最平滑的双向缓动
scrub: 2  // 最平滑的滚动关联

// 三合一效果
x: (index % 2 === 0 ? -80 : 80) → 0  // 横向
scale: 0.85 → 1  // 缩放
opacity: 0 → 1  // 淡入

// 额外的3D效果
rotationY: 0 → 3 → 0  // 轻微3D翻转

// 模糊效果
filter: 'blur(5px)' → 'blur(0px)'
```

#### 优化点
1. **三合一**: 横向+缩放+淡入，效果丰富
2. **power3.inOut**: 最平滑的双向曲线
3. **轻微3D**: rotationY 3°，立体感
4. **模糊过渡**: blur 5px到0px
5. **scrub 2**: 最平滑，慢而优雅

#### 适用场景
- 重要内容
- 首页hero
- 品牌介绍
- 需要优雅感的场景

## 📊 技术对比

### Ease曲线对比

| Ease | 特点 | 适用场景 |
|------|------|----------|
| power1.inOut | 线性加速减速 | 通用 |
| power2.inOut | 平滑加速减速 | 推荐 |
| power3.inOut | 强烈减速 | 最平滑 |
| back.out(1.7) | 弹性过冲 | 有活力 |
| sine.inOut | 正弦曲线 | 循环 |
| power1.out | 简单减速 | 通用 |
| power2.out | 平滑减速 | 推荐 |
| power3.out | 强烈减速 | 落地感 |
| none | 线性 | 循环 |

### Scrub值对比

| Scrub | 特点 | 适用场景 |
|-------|------|----------|
| 0.5 | 紧凑，响应快 | 需要快速响应 |
| 1.0 | 标准，平衡 | 通用 |
| 1.2 | 较平缓 | 常用 |
| 1.5 | 平滑，舒适 | 推荐 |
| 1.8 | 缓慢，优雅 | 慢速浏览 |
| 2.0 | 最平滑，慢速 | 精致体验 |
